# RZA для VS Code

[English version](README.md)

RZA — низкоуровневый язык с явным временем жизни памяти и проверяемым доступом
к ней. Это расширение добавляет подсветку синтаксиса, диагностику компилятора и
навигацию по языку для файлов `.rza` в Visual Studio Code.

Расширение запускает тот же компилятор `rez3asm`, который используется из
командной строки. Отдельной реализации правил языка в расширении нет.

## Возможности

- Подсветка инструкций, регистров, layouts, полей, чисел и комментариев.
- Диагностика через настоящий языковой сервер `rez3asm --lsp`.
- Hover для layouts, полей, рамок, ячеек, медиаторов и процедур.
- Go-to-definition и references внутри документа с точными диапазонами имён.
- Prepare rename и проверяемый rename для layouts, полей, рамок, ячеек, медиаторов
  и процедур. Edits содержат версию документа и возвращаются только если новая
  программа проходит checker компилятора.
- Контекстный completion для typed-полей и видимых операндов объявлений.
- Поддержка typed layouts: `layout`, `u8`, `i64` и доступ `.field`.
- Документация на английском и русском языках.

Каждый `.rza` — самостоятельная программа без межфайловых ссылок, поэтому навигация
и rename работают внутри текущего документа. Labels не поддерживаются. Rename
требует корректный текущий документ. Компилятор не входит в VSIX.

## Требования

- VS Code 1.82.0 или новее.
- Рабочий компилятор RZA, отдельно собранный из его исходного проекта.
- Node.js 22.14.0 только для разработки и проверки расширения.

Соберите компилятор по инструкциям его проекта. Дополнительный runtime для
расширения не требуется.

## Установка

### Из VSIX

В каталоге расширения:

```sh
npm ci
npm run package
code --install-extension build/rza-0.5.0.vsix
```

После установки перезапустите VS Code.

### Из исходного дерева

Скопируйте этот каталог как `rza-0.5.0` в каталог расширений VS Code, выполните
там `npm ci` и перезапустите VS Code. Для разработки можно использовать симлинк.
Если расширение установлено вне дерева исходников, задайте путь к компилятору
явно, как показано ниже.

## Путь к компилятору

Настройка называется `rez3.transpilerPath`.

Оставьте её пустой, если расширение находится в `editors/vscode` внутри дерева
исходников компилятора. В другом расположении укажите абсолютный путь к
компилятору в настройках пользователя или рабочей области:

```json
{
  "rez3.transpilerPath": "<absolute-path-to-compiler>"
}
```

После изменения настройки перезагрузите окно VS Code. Если файла нет или путь
указывает не на обычный файл, расширение объяснит проблему и предложит открыть
настройку.

## Пример typed layout

```asm
layout Entry: key:i64, value:i64
res entries, field, Entry[2]
med entries_m, entries, field
mov %r0, 0
mov %r1, 42
store [entries_m + %r0].key, %r1
store [entries_m + %r0].value, %r1
load %r2, [entries_m + 0].value
print %r2
ret
```

Индекс после медиатора — номер элемента, а не смещение в байтах. Размер записи и
смещения полей вычисляет компилятор. Неизвестное поле отображается настоящим
языковым сервером как диагностика `STRUCT`.

## Разработка и проверка

```sh
npm ci
npm test
npm run test:integration
npm run test:package
npm run package
```

- `npm test` проверяет tokens грамматики, пути к компилятору и публичные файлы.
- `npm run test:integration` скачивает VS Code 1.146.0 и запускает настоящее
  расширение с настоящим языковым сервером. На headless Linux используйте
  `xvfb-run -a npm run test:integration`.
- `npm run test:package` проверяет содержимое архива через Node ZIP reader.
- `npm run package` создаёт `build/rza-0.5.0.vsix` без добавления его в git.

Dependencies, загруженные VS Code, логи и пакеты игнорируются git.

## Устранение проблем

**Компилятор не найден.** Проверьте `rez3.transpilerPath`, соберите компилятор и
перезагрузите окно.

**Нет диагностики.** Проверьте language mode `rza`, наличие компилятора и то, что
документ находится внутри открытой рабочей области. Канал вывода RZA в VS Code
может показать ошибку запуска языкового сервера.

**Typed документ отклонён.** Откройте его напрямую через `rez3asm`. Расширение и
командный checker должны сообщать одну ошибку: расширение не смягчает правила.

**Память и host C.** Компилятор определяет поведение `.rza`, но не делает
произвольный host C безопасным.
